## FR-01 批量入库创建

### 目标

验证批量入库可以通过多轮供应商选择构建待创建明细，按供应商生成入库单，并保留重复物料明细。

### 前置数据

- 准备两个供应商，记为供应商 A 和供应商 B。
- 供应商 A 至少有一个可入库物料、包装器具、目标仓库和目标库位。
- 供应商 B 至少有一个可入库物料、包装器具、目标仓库和目标库位。

### 操作步骤

1. 登录 Web 前端。
2. 进入 `入库管理 -> 批量入库`。
3. 添加供应商 A 的一条物料明细，填写入库数量，确认系统显示箱数和零头。
4. 再添加供应商 A 的一条相同物料、相同数量明细。
5. 勾选供应商 A 的两条待创建明细，批量设置同一目标仓库和目标库位。
6. 添加供应商 B 的一条物料明细，设置目标仓库和目标库位。
7. 确认所有待创建明细均包含供应商、物料、容器类型、入库数量、箱数、零头、目标仓库和目标库位。
8. 提交创建。
9. 在入库单列表查询本次创建结果，并释放生成的入库单。
10. 打开生成的库存标签列表或库存标签打印页，核对库存标签追溯信息。

### 预期结果

- 所有待创建明细设置目标仓库和目标库位后才允许提交。
- 系统按供应商生成两张入库单。
- 供应商 A 的入库单包含两条独立明细，重复物料不自动合并。
- 库存标签按入库单明细行生成，每个标签能追溯到入库单号、明细行号、供应商、物料、数量、容器类型和目标仓库/库位。

### 判定标准

- 通过：批量入库主路径可完成，按供应商拆单和重复物料保留均正确。
- 有条件通过：批量创建成功，但箱数/零头或批量库位设置展示存在轻微缺失，不影响入库单与标签生成。
- 不通过：无法提交批量入库，或重复物料被合并，或不同供应商未拆成不同入库单。

## FR-02 批量出库与 FIFO 推荐

### 目标

验证批量出库创建出库需求后，系统展示 FIFO 推荐方案，并在推荐与非推荐扫码路径上保持一致业务规则。

### 前置数据

- 准备一张包含多条明细的出库单，或通过批量出库入口创建一张多明细出库单。
- 至少准备一个推荐方案中的库存标签。
- 至少准备一个同物料但不在当前推荐方案中的可用库存标签。

### 操作步骤

1. 登录 Web 前端。
2. 进入出库单页面，创建或打开一张多明细出库单。
3. 打开该出库单的 FIFO 推荐方案。
4. 核对推荐方案中的库存标签码、物料、仓库/库位、当前剩余数量、本次建议出库数量、零头标识和推荐顺序。
5. 进入带单出库扫码页面，使用推荐方案中的库存标签扫码或手工输入出库。
6. 再使用不在推荐方案中的同物料库存标签扫码或手工输入。
7. 在非推荐确认弹窗中先取消，确认本次不执行出库。
8. 再次扫描同一非推荐库存标签，在确认弹窗中选择继续。
9. 打开出库历史和库存标签详情，核对实际出库数量与库存标签剩余数量。

### 预期结果

- 出库单可展示 FIFO 推荐方案，推荐内容足以指导现场拣货。
- 推荐标签直接执行出库。
- 非推荐标签弹出“当前出库库存标签不在推荐出库方案中，是否继续按非推荐方案出库？”确认。
- 用户取消时不执行出库；用户确认时继续出库。
- 已封存、已出完、已取消、物料不匹配或无可用剩余数量的库存标签仍被拒绝。
- 出库历史记录实际出库结果。

### 判定标准

- 通过：推荐方案展示、推荐出库、非推荐取消和非推荐确认出库均正确。
- 有条件通过：主路径正确，但推荐方案部分辅助字段展示不完整。
- 不通过：非推荐库存标签不弹窗即出库，或取消后仍扣减库存。

## FR-03 手机端待处理出库单

### 目标

验证手机端 H5 只展示待处理出库单，并可进入出库单详情按推荐方案扫码处理。

### 前置数据

- 准备一张待出库、出库中或部分出库状态的出库单。
- 准备一张已完成或已取消出库单，用于列表排除验证。
- 手机端可使用摄像头扫码、图片识别或手工输入作为验收输入方式。

### 操作步骤

1. 打开 `http://localhost:5173/mobile/outbound`。
2. 未登录时确认系统跳转登录页，并使用 `admin` / `123456` 登录。
3. 查看待处理出库单列表。
4. 确认列表展示出库单号、出库用途、创建时间、明细数量、待出库总数量和状态。
5. 确认已完成或已取消出库单不在列表中。
6. 点击一张待处理出库单。
7. 查看出库单基本信息、出库明细、FIFO 推荐方案、已扫码出库进度和剩余待出库数量。
8. 按推荐方案扫描库存标签，或手工输入库存标签码并提交出库。
9. 完成该出库单所有待出库数量后，返回手机端待处理列表。

### 预期结果

- 手机端只显示待出库、出库中和部分出库单据。
- 已完成或已取消单据不显示。
- 出库单详情页展示推荐方案和出库进度。
- 手机端与网页端使用同一套 FIFO 推荐和非推荐出库确认规则。
- 出库完成后，该单据不再出现在手机端待处理列表中。

### 判定标准

- 通过：待处理列表过滤、详情展示和推荐出库主路径均正确。
- 有条件通过：主路径正确，但部分列表辅助字段显示不完整。
- 不通过：完成或取消单据仍显示，或待处理单据无法进入扫码处理页。

## FR-04 库存标签批量打印

### 目标

验证库存标签支持打印选中项和按入库单打印全部标签，且批量打印预览符合标签卡要求。

### 前置数据

- 准备一张已释放并生成多个库存标签的入库单。
- 至少准备两个可勾选的库存标签。
- 验收使用浏览器打印预览即可，不要求真实标签机或打印机。

### 操作步骤

1. 登录 Web 前端。
2. 打开入库单库存标签打印页。
3. 勾选多个库存标签。
4. 点击批量打印选中项。
5. 在打印预览中核对每个库存标签的标签卡。
6. 返回入库单详情或库存标签入口，使用按入库单打印全部库存标签入口。
7. 再次打开打印预览，核对该入库单全部库存标签均在预览中。
8. 触发浏览器打印预览或打印动作。

### 预期结果

- 选中项打印只包含用户勾选的库存标签。
- 按入库单打印全部库存标签包含该入库单全部库存标签。
- 每个库存标签是一张独立带边框标签卡。
- 标签卡至少展示库存标签码、二维码、入库单号、明细行号、供应商、物料编码、物料名称、数量、目标仓库/库位、容器类型和箱号或标签序号。
- 页面可触发浏览器打印预览或打印动作。

### 判定标准

- 通过：选中项打印、按入库单全量打印和标签卡关键信息均正确。
- 有条件通过：打印预览主路径可用，但个别辅助字段展示不完整。
- 不通过：无法批量打印，或选中项与全量打印范围错误。

## FR-05 库存详情短缺筛选

### 目标

验证库存详情页基于可用数量和 `lowStockQty` 展示短缺状态，并支持只看短缺和按供应商筛选。

### 前置数据

- 准备一个已配置 `lowStockQty` 的物料，且 `availableQty <= lowStockQty`。
- 准备一个已配置 `lowStockQty` 的物料，且 `availableQty > lowStockQty`。
- 准备一个未配置 `lowStockQty` 的物料。
- 准备至少两个供应商，用于供应商筛选。

### 操作步骤

1. 登录 Web 前端。
2. 在物料资料中确认或设置低库存阈值。
3. 打开库存总览或库存详情页面。
4. 查看物料列表中的可用数量、锁定数量、封存数量、手锁数量和库位分布。
5. 确认短缺物料展示短缺标识并前置。
6. 开启只看短缺。
7. 按供应商筛选全部物料。
8. 在供应商筛选条件下继续开启只看短缺。
9. 查看未配置 `lowStockQty` 的物料展示状态。

### 预期结果

- 短缺按 `availableQty <= lowStockQty` 判断，不使用账面数量。
- `availableQty > lowStockQty` 的物料显示正常。
- 未配置 `lowStockQty` 的物料不参与短缺判断，可显示“未配置阈值”。
- 短缺物料前置展示。
- 只看短缺只保留短缺物料。
- 按供应商筛选和按供应商筛选短缺物料均可用。
- AI 预警入口、智能推荐和外部预测不参与本验收。

### 判定标准

- 通过：短缺判断、短缺前置、只看短缺和供应商筛选均正确。
- 有条件通过：短缺判断正确，但未配置阈值的展示文案不完整。
- 不通过：短缺使用了错误数量口径，或供应商筛选后短缺结果错误。

## FR-06 手机端库存封存/解封

### 目标

验证手机端 H5 可扫码查询库存标签，并执行原因必填的封存和确认式解封。

### 前置数据

- 准备一个未封存、未出完、未取消且剩余数量大于 0 的库存标签。
- 准备一个已封存库存标签，或使用本验收步骤封存后的库存标签继续解封。
- 手机端可使用摄像头扫码、图片识别或手工输入作为验收输入方式。

### 操作步骤

1. 打开 `http://localhost:5173/mobile/seal`。
2. 未登录时确认系统跳转登录页，并使用 `admin` / `123456` 登录。
3. 扫描或手工输入一个可用库存标签码。
4. 查看库存标签码、物料、当前仓库/库位、剩余数量、当前状态和是否已封存。
5. 不填写封存原因直接点击封存。
6. 填写封存原因和可选备注后提交封存。
7. 在网页端库存标签列表或库存监控中查询该库存标签。
8. 回到手机端，再次扫描该库存标签。
9. 点击解封，并在二次确认中选择取消。
10. 再次点击解封，并在二次确认中选择确认。
11. 再次在网页端库存标签列表或库存监控中查询该库存标签。
12. 尝试扫描已出库、已取消或无剩余数量的库存标签，观察错误提示。

### 预期结果

- 手机端封存页面可查询库存标签详情。
- 封存原因必填，备注可选。
- 封存成功后，库存标签状态、可用数量和封存数量同步更新。
- 已封存库存标签提供解封操作。
- 解封只需要二次确认，不要求填写原因或备注。
- 解封取消时不改变库存标签状态；确认后库存标签恢复可用状态。
- 已出库、已取消、无剩余数量或其他不可操作状态的库存标签不能执行封存/解封，并显示明确错误。

### 判定标准

- 通过：手机端封存、原因必填、解封确认和网页端状态同步均正确。
- 有条件通过：主路径正确，但不可操作状态的错误提示不够具体。
- 不通过：手机端无法封存/解封，或封存后网页端库存状态不同步。
