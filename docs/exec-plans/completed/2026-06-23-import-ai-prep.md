# Week 4 WP4-04 批量导入与数据准备执行计划

## 目标

提供表格批量导入能力，并让导入数据能支撑库存演示、监控查询和后续 AI 预警分析。

## 范围

- 选择首期导入对象。
- 定义导入模板和字段校验。
- 实现导入接口、错误行反馈和导入摘要。
- 准备样例数据，覆盖物料、时间、数量、库位、状态和操作类型等分析字段。

首期不做复杂 Excel 样式解析、异步大文件任务队列和外部系统导入。

## 活动拆解

| 活动 | 内容 | 输入 | 输出 | 验收标准 |
| --- | --- | --- | --- | --- |
| ACT-01 导入对象选择 | 在物料、供应商、仓库库位、入库单、库存初始化中选择首期对象 | 总体需求规格 | 导入对象和模板字段 | 首期对象能支撑演示或 AI 数据准备 |
| ACT-02 模板与校验 | 定义表头、必填项、唯一性、引用校验和错误格式 | ACT-01 | 模板说明和校验规则 | 错误行能明确指出原因 |
| ACT-03 后端导入接口 | 实现文件接收、解析、校验、写入和摘要返回 | ACT-02 | 导入 API | 成功/失败数量和错误明细可返回 |
| ACT-04 前端导入页面 | 上传文件、展示校验结果和导入摘要 | ACT-03 | 导入页面 | 用户能看到错误行和成功摘要 |
| ACT-05 样例数据 | 准备可用于库存监控和 AI 预警的数据样例 | ACT-01/02 | 样例文件或种子数据 | 数据字段满足缺货/呆滞分析准备 |
| ACT-06 验证 | 测试和手动导入验证 | ACT-03 至 ACT-05 | 验证记录 | 至少一个高价值数据集可导入 |

## 依赖

- 可与 WP4-01、WP4-02、WP4-03 的早期活动并行。
- AI 字段准备依赖 WP4-05 对缺货/呆滞预警字段的定义。
- 如果选择导入入库单或库存初始化，需要遵循 WP4-01 的库存口径。

## 验证

- 后端：`cd backend && mvn test`
- 前端：`cd frontend && npm test`
- 构建：`cd frontend && npm run build`
- 手动验证：上传包含成功行和失败行的样例表格，确认摘要和错误行反馈。

## 风险

- 导入范围过大容易拖慢本周交付，应先选择一个最能支撑演示的数据集。
- 表格格式如果不稳定，应优先固定模板，不做自由格式解析。
