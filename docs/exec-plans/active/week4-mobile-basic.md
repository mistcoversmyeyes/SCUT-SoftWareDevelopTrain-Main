# Week 4 WP4-02 手机端基本功能执行计划

## 目标

提供手机端基本扫码能力，支撑登录、入库扫码、出库扫码和看板查询演示。首期优先实现移动端 H5 或响应式页面，不接入真实 PDA 设备协议。

## 范围

- 手机端登录和会话保持。
- 看板码扫码或手工输入。
- 扫码入库。
- 带单/不带单扫码出库的基础路径。
- 看板状态查询和异常提示。

不做原生 Android 工程、扫码枪协议、离线缓存和复杂权限体系。

## 活动拆解

| 活动 | 内容 | 输入 | 输出 | 验收标准 |
| --- | --- | --- | --- | --- |
| ACT-01 端形态确认 | 确认采用移动端 H5/响应式页面，复用现有 Vue 项目和 API | 总体需求规格 | 页面路由和入口方案 | 不新增原生工程依赖 |
| ACT-02 API 适配 | 梳理移动端调用的登录、入库、出库、看板查询接口 | 现有 API wrapper | 移动端 API wrapper 或复用说明 | 所需接口可从手机端页面调用 |
| ACT-03 移动端布局 | 设计移动端导航、扫码输入、结果反馈布局 | ACT-01 | 移动端页面骨架 | 小屏下主要操作不溢出 |
| ACT-04 入库扫码页 | 实现看板码输入、库位选择、提交入库、结果展示 | ACT-02/03 | 手机入库页面 | 可完成一次扫码入库演示 |
| ACT-05 出库扫码页 | 实现带单/不带单出库入口、扫码提交和异常提示 | ACT-02/03 | 手机出库页面 | 可完成基本出库演示 |
| ACT-06 看板查询页 | 展示看板生命周期、位置、数量和锁定/封存状态 | ACT-02/03 | 手机看板查询页面 | 输入看板码可查询状态 |
| ACT-07 验证 | 前端测试、构建和手机视口手动验证 | ACT-04 至 ACT-06 | 验证记录 | 移动端主路径可演示 |

## 依赖

- 可与 WP4-03 的页面骨架并行。
- 看板封存状态展示依赖 WP4-01 的状态口径。
- 出库异常提示依赖 WP4-01 对散件/FIFO 的最终错误语义。

## 验证

- 前端：`cd frontend && npm test`
- 构建：`cd frontend && npm run build`
- 手动联调：手机视口登录、入库扫码、出库扫码、看板查询。

## 风险

- 真实扫码能力可能受浏览器权限和 HTTPS 限制影响，首期保留手工输入兜底。
- 当前认证仍是 demo token，不能代表正式用户权限。
